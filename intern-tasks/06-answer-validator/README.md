# Answer validator

Задание 06 направления «База знаний и агент вопросов и ответов». Проект отделяет
создание черновика ответа от независимой проверки ссылок на исходные фрагменты.

## Подготовка

Выполняйте команды из каталога `intern-tasks/06-answer-validator`:

```bash
uv sync --python 3.11
```

Для основной проверки ключ и сеть не нужны. Необязательный OpenAI-совместимый
переходник устанавливается так:

```bash
uv sync --extra llm --python 3.11
```

Секрет передаётся только через `LLM_API_KEY`; пример переменных находится в
`.env.example`.

## Как проходит ответ

1. `AnswerComposer` получает вопрос и найденные фрагменты.
2. `FakeAnswerComposer` возвращает заранее заданный `DraftAnswer` без сети.
3. Чистая функция `validate_answer()` проверяет каждое утверждение.
4. Неизвестная ссылка, пустой список ссылок, устаревшая редакция или выдержка,
   отсутствующая в источнике, отклоняют утверждение.
5. При частичном покрытии неподтверждённые утверждения удаляются.
6. Если подтверждённых утверждений нет, возвращается `status="abstained"`.

`answer_text` собирается только из прошедших проверку утверждений. Поле `summary`
черновика напрямую пользователю не выдаётся, потому что модель могла добавить в
него неподтверждённый текст.

## Актуальность редакций

`RetrievedChunk.revision_observed_at` содержит время регистрации редакции. Если
доступны две редакции одного `source_id`, принимается только самая новая. Если
время хотя бы одной редакции неизвестно, ссылки на неоднозначный источник
консервативно отклоняются с причиной `STALE_CITATION`.

## Защита от инструкций в документах

OpenAI-переходник передаёт пронумерованные фрагменты внутри пользовательского
сообщения и явно обозначает их как недоверенные данные. Текст документа никогда
не становится системной инструкцией. Итоговые идентификаторы всё равно проверяет
`validate_answer()`.

## Локальная демонстрация

```bash
uv run python -m answer_validator
```

Демонстрация использует только синтетический файл `data/fixtures/example.json`.
Один подтверждённый факт остаётся в ответе, а утверждение без ссылки удаляется.

## Стандартные проверки

```bash
uv run ruff check .
uv run pytest -q -m 'not integration and not llm'
uv run python -m compileall -q src tests
```

Модульные тесты работают без сети и API-ключа. Они проверяют пустой контекст,
неизвестные и отсутствующие ссылки, две правильные ссылки, устаревшую редакцию,
отсутствующую в источнике выдержку, частичное покрытие и полный сценарий через
`FakeAnswerComposer`. Отдельная проверка подтверждает, что вредоносная инструкция
из документа остаётся данными пользовательского сообщения и не попадает в
системную инструкцию.
