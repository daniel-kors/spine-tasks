# Удалённая работа

## Доступность

Сотрудник должен быть доступен в общем интервале с 11:00 до 16:00 по московскому
времени.

## Рабочее место

Компания компенсирует оборудование рабочего места один раз в два года в пределах
35 000 рублей после согласования с руководителем.

## Поездки в офис

Для полностью удалённых сотрудников проезд в офис согласуется отдельно и не
считается командировкой без письменного распоряжения.
