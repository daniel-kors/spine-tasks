# Данные для ассистента коммерческих предложений

## Состав

- `historical-cases.csv` — 12 исторических кейсов рабочей области `alpha`;
- `historical-cases-beta.csv` — три записи другой рабочей области для проверки изоляции;
- `requests/` — вымышленные запросы клиентов;
- `estimates/` — исторические сметы с денежными значениями в строках;
- `new-requests/` — 15 запросов для извлечения требований и поиска аналогов;
- `policies/v1.json` — правила полноты;
- `pricing/cases.jsonl` — десять заранее рассчитанных денежных примеров;
- `evals/v1.jsonl` — 36 примеров итоговой проверки;
- `templates/proposal.md.j2` и `expected/proposal.md` — шаблон и ожидаемый результат.

Все клиенты, адреса, проекты и суммы вымышлены. Значения денег представлены
строками, чтобы при чтении использовать `Decimal`, а не `float`.

Пути в CSV указаны относительно этого каталога. При копировании отдельных файлов
в задание сохраняйте взаимное расположение `requests/` и `estimates/`.
