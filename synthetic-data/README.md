# Синтетические данные

Каталог содержит полностью вымышленные данные для двух направлений:

- `01-knowledge-base-and-qa/` — база знаний и служба вопросов и ответов;
- `02-commercial-proposal-assistant/` — ассистент коммерческих предложений.

Данные не содержат сведений реальных компаний и людей. Их можно копировать в
каталог `data/fixtures/` соответствующего задания. Подробности и ожидаемые
результаты приведены в README каждого набора.
