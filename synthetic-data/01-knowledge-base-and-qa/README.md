# Данные для базы знаний и службы вопросов и ответов

## Состав

- `documents/alpha/` — документы рабочей области `alpha`;
- `documents/beta/` — отдельная рабочая область для проверки изоляции;
- `access-map.json` — группы доступа и актуальные редакции;
- `retriever/fake-results.json` — ответы программной заглушки;
- `questions/manual-check.jsonl` — десять вопросов для ручной проверки Cognee;
- `evals/v1.jsonl` — 30 размеченных примеров для задания 09;
- `invalid/` — пустой документ и намеренно повреждённая строка JSONL.

Файлы `travel-policy-v1.md` и `travel-policy-v2.md` — две редакции одного
источника `travel-policy`. Актуальной считается вторая. Файл
`engineering-only.md` разрешён только группе `engineering`. Документы рабочей
области `beta` нельзя возвращать пользователям из `alpha`, даже если их текст
совпадает.

Все строки JSONL являются самостоятельными объектами JSON. Файлы проверены на
корректность синтаксиса, кроме содержимого каталога `invalid/`, где ошибка
создана намеренно.
