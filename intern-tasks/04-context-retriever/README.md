# Context retriever

Задание 04 направления «База знаний и агент вопросов и ответов». Проект задаёт
собственный контракт получения контекста и управляемую программную заглушку.
Прикладной код зависит от интерфейса `Retriever` и не знает ничего о Cognee.

## Подготовка

Выполняйте команды из каталога `intern-tasks/04-context-retriever`:

```bash
uv sync --python 3.11
```

Версии зависимостей находятся в `uv.lock`. `access-map.json`, документы и
`retriever/fake-results.json` скопированы без изменений из синтетического набора
направления 01.

## Известный вопрос

```bash
uv run python -m context_retriever.demo
```

Ожидаемый результат:

```text
Найдено фрагментов: 1
Источник: travel-policy
Редакция: 11111111-1111-4111-8111-222222222222
Текст: С 1 сентября суточные для поездок по России составляют 1200 рублей в день.
```

Заглушка получает готовый фрагмент по точному тексту вопроса. Она не открывает
документы, не анализирует слова и не выполняет поиск.

## Неизвестный вопрос

```bash
uv run python -m context_retriever.demo --question "Неизвестный вопрос"
```

Заглушка вернёт `Найдено фрагментов: 0`.

## Настроенная ошибка

```bash
uv run python -m context_retriever.demo --question "Проверка недоступности Cognee"
```

Команда напечатает `CONTEXT_PROVIDER_UNAVAILABLE` и завершится с ненулевым кодом.

## Состав пакета

- `models.py` — запрос, ссылка, фрагмент и результат;
- `contracts.py` — асинхронный интерфейс `Retriever`;
- `fake_retriever.py` — управляемая заглушка без внешнего ввода-вывода;
- `configuration.py` — преобразование готового JSON в модели;
- `demo.py` — прикладной пример, зависящий только от контракта.

## Локальные проверки

```bash
uv run ruff check .
uv run pytest -q -m 'not integration and not llm'
uv run python -m compileall -q src tests
```

Тесты используют `tests/factories.py` и проверяют контракт заглушки, Pydantic-модели,
готовую конфигурацию, настроенную ошибку и отсутствие зависимости от Cognee.
